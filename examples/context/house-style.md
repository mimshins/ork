# House style

- Write for the person who reads it next: short sentences, plain words, the
  important part first.
- Name things for what they do. Prefer a clear long name to a clever short one.
- Comments explain why, never what the next line already says.
- Every user-facing message says what happened and what to do next.
- Keep changes small and focused; one idea per commit, with a message that says
  why.
