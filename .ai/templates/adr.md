# ADR template

Copy to `decisions/ADR-NNN-<kebab-title>.md` (the next free number, never
reused). Self-contained: a reader with only this file understands the decision
and why. See `decisions/README.md`, and add a row to its index.

```md
# ADR-NNN — <Title>

- **Status:** Accepted
- **Date:** YYYY-MM-DD
- **Topic:** <area>
- **RFC:**
  [RFC-NNN](../rfcs/archived/RFC-NNN-<kebab>.md) <!-- or: waived — <why> -->

## Context

_What forced the decision._

## Decision

_What was decided, precisely. Link the spec and code that carry the detail._

## Options considered

_The alternatives, especially when the RFC step was waived._

## Rationale

_Why this over the alternatives._

## Consequences

_What changed, follow-ups, and what to watch out for._
```
