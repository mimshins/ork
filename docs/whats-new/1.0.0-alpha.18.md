# 1.0.0-alpha.18

_Part of [What's new](../whats-new.md)._

- **Sessions and your store are kept private.** `~/.ork/` is now readable only
  by you (`0700`, and `state.db` `0600`), and a `claude-code` session gets its
  MCP servers and settings in private files, not on its command line. On
  `command-code`, a shell line is checked command by command, and a read by its
  real path. A run's reported branch that isn't a plain branch name is dropped
  ([where Ork keeps things](../guides/where-ork-keeps-things.md#in-your-home-folder-ork),
  [drivers](../guides/drivers.md#permissions-denied-unless-allowed)). Upgrade:
  on `command-code`, a node that chains commands (`a && b`) needs a rule for
  each, or a plain `Bash` rule.
